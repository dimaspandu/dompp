Reactive Server Messenger

Demonstrates server DOM adoption with componentBuilder. The component adopts an existing server-rendered root and rerenders a keyed message list when new messages are added.

How it works: elementBuilder(messengerNode, ...) adopts the existing root. componentBuilder provides rerender, and the SEND action updates the in-memory array before rebuilding the descriptor tree.
