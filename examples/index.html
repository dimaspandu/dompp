DOM++ Examples

Progressive examples showcasing native-first DOM manipulation, components, and safety.

    Native DOM nodes with chainable setters. No wrappers, no virtual DOM.

  • 02 Components and MVVM

    Components with explicit rerender and ViewModel-driven state.

  • 03 JSX and Adoption

    JSX syntax and adopting existing markup in place.

  • 04 Dynamic Lists

    Conditional rendering and keyed lists with identity preservation.

  • 05 Fragments and Arrays

    Multi-root fragments and array-returning components.

  • 06 Safe by Default

    Built-in guards against dangerous attributes and protocols.

  • 07 Capstone Mini App

    Combining components, state, lists, and fragments in one app.

  • 08 Local Stateful Subtree

    A stateless outer view with an embedded stateful component.

  • 09 Add and Remove Subtree

    Dynamically mount and unmount subtrees.

  • 10 Adopt Server Markup

    Adopt existing server-rendered markup, then rerender reactively.

  • 11 Guided Tour

    A guided tour from direct DOM control to reactive components, dynamic structure, composition, and adoption.
