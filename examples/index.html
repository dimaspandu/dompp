Interaction Patterns

A guided tour from direct DOM control to reactive components, dynamic structure, composition, and adopting existing markup. The original ElementBuilder and ComponentBuilder engine remains the foundation; document enhancement is an adapter, while JSX is only an alternative syntax.

document.hydrateElement(existingNode, ...) preserves server markup that is not described in the virtual tree (non-destructive hydration). Use document.createElement(existingNode, ...) when you want reconcile behavior that replaces old children not in the new tree.

12 · CROSS-COMPONENT UPDATE

Components rerender each other directly

document.createComponent returns the element with a .rerender() method, so components can hold direct references to each other and trigger targeted updates without a parent intermediary.
