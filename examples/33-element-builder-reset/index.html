elementBuilder Outlet with reset()

Using elementBuilder on a shared outlet with .reset() to ensure a clean slate on each route change. This removes all attributes, styles, and children from the previous route before rendering the next.

How it works: .reset() clears the virtual struct (styles, attributes, children, events) and the live DOM node (removes all attributes, clears style, replaces children). Then setChildren() renders the new route view.
