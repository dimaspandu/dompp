Component Builder

componentBuilder is a small stateful render wrapper around elementBuilder trees. This example focuses on the JSX form and the rerender(callback) flow.

What

componentBuilder((rerender) => tree) returns a component instance with render() and rerender().

How

render() builds the initial tree. rerender(callback?) runs the optional state update first, rebuilds the next tree, then patches or replaces the root as needed.

Why

It keeps state transitions explicit and local while reusing DOMPP descriptor reconciliation, without a virtual DOM framework runtime.

In the demo, clicking UPDATE calls rerender(() => { count += 1; }). The callback executes before the view is rebuilt, so the returned JSX reads the updated count.
