Keyed List Reconciliation

Demonstrates stable keys with componentBuilder/elementBuilder. Keys help preserve item identity across append, prepend, reorder, and removal. Changing an item's tag forces node replacement for that item.

How it works: each item passes key: item.id to elementBuilder(...). Reconciliation matches keyed children by key and tag before falling back to positional reuse.
