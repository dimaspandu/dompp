MVVM with Component Builder

Demonstrates a layered MVVM pattern using elementBuilder and componentBuilder. The JSX view is rendered by a component builder; state changes flow through Model and ViewModel boundaries.

Model

Owns the data (count) and exposes minimal operations. It has no dependency on the View, ViewModel UI logic, or DOM.

ViewModel

Exposes Model data and actions (increment, decrement). When data changes, it notifies listeners.

View

Built with componentBuilder/JSX. It reads ViewModel getters and calls ViewModel actions. A ViewModel listener triggers view.rerender().

Why this pattern: responsibilities stay separated. The View does not mutate the Model directly, and the Model does not know about rendering. componentBuilder provides the explicit rerender boundary while elementBuilder handles descriptor reconciliation.
