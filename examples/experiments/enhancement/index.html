DOM++ · Enhanced Document API

Interaction Patterns

Five ways to build reactive interactions. The original ElementBuilder and ComponentBuilder engine remains the foundation; document enhancement is an adapter, while JSX is only an alternative syntax.

01 · BASIC DOM

Direct element mutation

Create elements with the builder API, keep references, and update only the nodes that change. No component rerender is involved.

02 · BASIC DOM + JSX

Familiar JSX syntax

Same direct-mutation approach as Example 01. JSX is compiled to document.createElement() calls.

03 · COMPONENT

Render and rerender

document.createComponent rebuilds the element description and patches the existing DOM when the state changes.

04 · MVVM

ViewModel subscription

The ViewModel owns the count and notifies subscribers. The view rerenders its component in response to updates.

05 · LOCAL STATEFUL IN STATELESS

Local stateful subtree inside a stateless view

A stateless view composes static structure and embeds a document.createComponent subtree. A ViewModel listener triggers rerender only for that local subtree.
