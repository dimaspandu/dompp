Element Builder

Introduces elementBuilder: a small virtual-descriptor API that can adopt or create DOM nodes, apply attributes/styles/events, and mutate specific nodes directly through returned builder instances.

What this example shows

document.elementBuilder (or elementBuilder in JSX) returns an ElementBuilder descriptor with a struct (tag, key, attributes, styles, events, children) and a materialized/adopted node when available.

The JavaScript version uses the builder factory directly. The JSX version uses a JSX factory that produces the same builder descriptors, so variables like countEl and buttonEl still reference builder instances that can be mutated with setStyles, setText, and setAttributes.
